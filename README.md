## 主要功能

- 游戏数据修改：角色、能力与法术、物品、食物、武器、基因、家园等数据。
- 生成与查询：物品生成、NPC 生成、玩家信息、事件概率和 NPC 图鉴。
- 独立功能：战斗与角色保护、制作、采集、种植、分解、信仰与神龛、装备对比、经验显示、充能、盗窃、地牢及世界相关功能。
- 大型模块：自动化、月门云存储、AI 辅助、插件管理、威胁覆盖层和更多信息显示。
- UI：多页面运行时界面、配置保存与读取、主题及显示设置。

具体功能以当前游戏内界面和版本为准。多数修改功能默认可独立开关，关闭后恢复对应的游戏原有处理逻辑；部分会直接修改存档数据的操作无法通过卸载插件自动撤销。
项目包含 Stable 与 Nightly 的兼容处理路径，但不保证永久兼容所有未来游戏版本。游戏更新后，如果原版类型、字段、方法或 Harmony Patch 目标发生变化，可能需要更新插件。

## 运行要求

- 可加载 BepInEx 插件的游戏环境

## 网络与隐私

部分功能会使用网络连接：

- 月门云存储会在用户主动上传或下载时传输相应的地图、地图元数据及容器数据。
- AI 辅助会把用户提交的内容和所需上下文发送到用户配置的接口；API Key 会以明文形式保存在本地配置文件中。

使用相关功能前，请阅读程序内显示的使用条款和隐私说明。完整文本也位于仓库的 `Terms/` 目录。
