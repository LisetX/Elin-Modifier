4. Moongate, Cloud Index, and Map Upload

When you open the Moongate module or actively refresh the page, the Mod obtains the official Moongate index and the Elin Modifier cloud index over HTTPS. Search, language, and source filtering are generally performed on the index downloaded to your device. When you enter a map that is not already cached, the Mod downloads the map file from the corresponding official address, an index-provided download address, or the Elin Modifier cloud storage endpoint and stores it in the game's local Moongate cache directory.

The Mod exports and uploads the current map only when you actively click “Upload map to Elin Modifier cloud storage server.” The upload request may contain:

1. The raw SteamID64 of the current Steam account as owner_id, used to identify the uploader, derive a stable map identity, and process updates by the same uploader;
2. A local map_key composed from the current save-directory identifier and zone UID;
3. An update_key used to authorize later updates of the same map;
4. The PC display or character name, map title, language region, map category, tags, and game version;
5. The complete exported current-map file, including map, object, character, text, and other zone data included by the game's export process;
6. Player-created containers, their lock levels, and complete game data for items stored inside those containers.

The SteamID64, map_key, and update_key are transmitted to the Elin Modifier Moongate server over HTTPS. They are used to identify the uploader, map, and update authority. The public index primarily displays map metadata such as map ID, title, author, language region, upload time, game version, and source. The upload update_key is stored in the Mod's local configuration. Losing that configuration may prevent future updates to the original map. Do not disclose the key.

After a successful upload, map metadata is added to the public index and the map file can be searched and downloaded by other users. Do not put information you do not want made public into a character name, map title, tags, map objects, custom text, NPCs, containers, or item data, and do not upload third-party content you lack the right to distribute. Map files and revision records may remain stored until replaced by a later version, removed by the developer, or deleted during service cleanup. The Mod currently provides no self-service interface for permanently deleting a cloud map. Use the contact information at the end of this document to request deletion.

Downloading and entering a map uploaded by another user may import third-party map content, objects, characters, and item data into the current game environment. The developer does not guarantee the accuracy, compatibility, legality, or continued availability of user-uploaded content. Decide whether to download and enter a map and back up your save when appropriate.

Moongate requests generate network-operational data such as IP address, request time, TLS/HTTP metadata, status code, and security logs. The server may process map files, metadata, uploader identifiers, and logs for as long as needed to provide index, upload, download, and update functions; prevent abuse; troubleshoot faults; and comply with legal obligations.
