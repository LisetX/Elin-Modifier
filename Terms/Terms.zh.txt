Elin Modifier 使用条款与隐私说明

条款版本：2026-08-08.1
最后更新日期：2026年8月8日

重要摘要

1. Elin Modifier 是非官方第三方游戏修改工具，会按您主动启用的功能读取或修改游戏运行数据；部分操作可能写入游戏存档。
2. AI 辅助为可选功能。只有您主动配置并使用时，输入内容、上下文、工具定义、工具执行结果以及相关游戏或插件数据才会发送到您指定的 AI 接口。API Key 会以明文保存在本 Mod 的本地配置文件中。
3. 本 Mod 会在本地配置文件中保存您已接受的条款版本。条款版本变化、字段缺失或版本不一致时，会再次要求您查看并确认。
4. 月门模块会联网获取地图索引并下载地图。只有您主动点击上传时，本 Mod 才会把原始 SteamID64、地图元数据和完整地图导出文件发送至 Elin Modifier 云存储服务器；地图文件可能包含地图对象、NPC、玩家创建的容器及其中的物品数据，上传后的公开元数据和地图文件可供其他用户搜索、查看和下载。

请继续阅读完整条款。点击“我已阅读隐私说明并同意使用条款”表示您确认已经阅读并同意本文件；点击“退出”将终止本 Mod 的本次加载。

一、适用范围与接受方式

本文件同时包含 Elin Modifier（以下简称“本 Mod”）的使用条款与隐私说明，适用于本 Mod 本体、内置功能、EMG 工具接口、EMP 插件管理、自动化、调试功能、AI 辅助及月门等模块。

您应当在具备相应民事行为能力并有权接受本条款的前提下使用本 Mod。若您不同意本条款中的任何内容，请点击“退出”、停止加载并删除本 Mod。

二、非官方性质与使用风险

本 Mod 是非官方第三方修改工具，与 Valve、Steam、Elin 的开发商或发行商不存在官方授权、隶属、合作或担保关系，除非另有明确书面说明。

本 Mod 的功能可能读取或修改游戏内存、角色与物品数据、运行逻辑、配置文件、插件工作区及游戏存档。错误设置、极端数值、游戏更新、插件冲突、自动化行为或运行时补丁可能导致游戏异常、性能下降、功能冲突、存档异常或数据丢失。请在使用前备份重要存档与配置，并自行判断是否启用高风险功能。

三、AI 辅助与第三方 AI 接口

AI 辅助默认需要您自行填写 API 地址、API Key 和模型名。只有在您主动获取模型列表、发送消息、压缩上下文或触发后续工具循环时，本 Mod 才会向您配置的接口发起请求。

根据您使用的功能，请求可能包含：

1. 您输入的消息及保留的对话上下文；
2. 本 Mod 的系统提示词、EMG 工具定义及可用能力说明；
3. 工具调用参数、执行结果、错误信息和中断原因；
4. 您要求 AI 读取或操作的游戏、角色、物品、NPC、插件、程序集、反编译缓存或运行时数据；
5. 模型名、思考强度、流式传输及其他请求参数。

API 地址、API Key、模型名及相关 AI 设置会保存在本 Mod 的本地 JSON 配置文件中。API Key 当前以明文形式保存，请妥善保护配置文件，不要将其公开、上传或发送给他人。API Key 会作为认证信息发送给您选择的 API 服务商。

本 Mod 自身不会把 AI 对话历史和最后一次 HTTP 请求/响应正文写入常规配置文件；这些内容通常仅保留在当前游戏进程内，清空历史或退出游戏后由本 Mod 释放。但您选择的 AI 服务商、代理服务、网络基础设施或日志系统可能按照其自身条款保留请求和响应。AI 导出的 EMP 文件、反编译缓存、编译临时文件及其他工作区产物属于本地文件，除非您自行上传，否则不会因该导出行为自动发送给开发者。

开发者无法控制您选择的第三方 AI 服务商如何处理数据。使用前请阅读该服务商的条款与隐私政策，不要在对话中输入不希望发送给该服务商的秘密、个人信息或第三方数据。

四、月门、云索引与地图上传

进入月门模块页面或主动刷新页面时，本 Mod 会通过 HTTPS 获取官方月门索引及 Elin Modifier 云索引。搜索、语言区和来源筛选通常在下载到设备的索引上执行。选择进入尚未缓存的地图时，本 Mod 会从对应的官方地址、索引提供的下载地址或 Elin Modifier 云存储接口下载地图文件，并保存在游戏的本地月门缓存目录中。

只有您主动点击“上传地图至 Elin Modifier 云存储服务器”时，本 Mod 才会导出并上传当前地图。上传请求可能包含：

1. 当前 Steam 账户的原始 SteamID64，作为 owner_id，用于识别上传者、计算稳定地图标识及处理同一上传者的地图更新；
2. 由当前存档目录标识和区块 UID 组成的本地 map_key；
3. 用于后续更新同一地图的 update_key；
4. PC 显示名称或角色名称、地图标题、语言区、地图分类、标签和游戏版本；
5. 当前地图的完整导出文件，包括游戏导出逻辑包含的地图、对象、角色、文本和其他区块数据；
6. 玩家创建的容器、容器锁定等级及容器内物品的完整游戏数据。

SteamID64、map_key 和 update_key 会通过 HTTPS 发送至 Elin Modifier 月门服务器。它们用于服务端识别上传者、地图及更新权限；公开索引主要展示地图 ID、标题、作者、语言区、上传时间、游戏版本和来源等地图元数据。上传用 update_key 会保存在本 Mod 的本地配置中，配置丢失可能导致无法更新原地图，请勿公开该密钥。

上传成功后，地图元数据会进入公开索引，地图文件可被其他用户搜索和下载。请勿在角色名、地图标题、标签、地图对象、自定义文本、NPC、容器或物品数据中放入您不希望公开的信息，也不得上传无权传播的第三方内容。地图文件及修订记录可能保留至被后续版本替换、由开发者删除或服务清理；本 Mod 当前不提供用户自行永久删除云端地图的接口，如需删除请通过本文件末尾的联系方式提出请求。

下载和进入其他用户上传的地图可能把第三方创建的地图内容、对象、角色及物品数据导入当前游戏环境。开发者不保证用户上传内容的准确性、兼容性、合法性或持续可用性。请自行判断是否下载和进入，并在必要时备份存档。

月门请求会产生网络运行必需的 IP 地址、请求时间、TLS/HTTP 元数据、状态码及安全日志。服务器可在提供索引、上传、下载、更新、防滥用、故障排查和履行法律义务所需的期限内处理相关地图文件、元数据、上传者标识和日志。

五、本地配置、工作区与游戏数据

本 Mod 会在本地保存运行所需的配置，例如：已接受的条款版本、语言和 UI 设置、功能开关、自动化配置、击杀成长记录、EMP 状态、月门上传更新密钥，以及您填写的 AI 接口设置。自动化执行配置、EMP 插件、Skill、反编译结果、编译缓存、月门收藏、下载缓存、持久化地图及其他功能文件也可能保存在本 Mod 目录、游戏存档、游戏月门缓存目录或 workspace 子目录中。

部分功能只修改当前进程内存，重启后恢复；部分功能会写入本 Mod 配置；另一些功能会直接修改游戏对象，并可能随游戏正常存档流程写入存档。具体结果取决于功能说明、游戏机制和您执行的操作。卸载本 Mod 不一定会撤销已经写入游戏存档的数据。

除您主动使用的 AI 接口请求、月门索引和地图下载、您主动发起的月门地图上传、您主动点击的官网链接以及实现这些网络功能所必需的通信外，本 Mod 当前不设计为向开发者发送常规游戏遥测、聊天记录、好友列表、库存列表、购买记录或支付信息。月门地图上传属于明确例外：上传文件可能包含地图容器内的物品数据，但不会因此自动上传 PC 背包中与地图导出无关的全部物品列表。
